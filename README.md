# 국민연금 사업장 데이터 기반 기업·업종 비교 대시보드

국민연금 가입 사업장 데이터를 정제하고, 기업별 급여 추정치와 동일 업종의 통계를 비교하는 **Python·Pandas·Streamlit 데이터 분석 프로젝트**입니다.

회사명을 입력하면 사업장 정보, 국민연금 가입자 수, 월·연 급여 추정치, 업종 평균 대비 차이를 표와 차트로 확인할 수 있습니다. 공공데이터를 기업 탐색에 활용할 수 있는 정보로 가공하고, 사용자가 직접 조회하는 웹 대시보드로 연결했습니다.

[Streamlit 앱 열기](https://pynpsmcp2607-qbttjymefx4wyv4xcw5kfh.streamlit.app/)

> 기존 안내 기준으로 배포 앱은 저장소 소유 계정의 접근 권한이 필요합니다. 접근이 어려운 경우 아래 실행 화면과 로컬 실행 방법으로 프로젝트를 확인할 수 있습니다.

## 프로젝트 목적

기업을 살펴볼 때 개별 수치만으로는 같은 업종에서의 상대적인 위치를 파악하기 어렵습니다. 이 프로젝트는 국민연금 사업장 데이터를 이용해 **검색한 기업의 급여 추정치가 동일 업종 평균과 얼마나 차이 나는지** 확인할 수 있도록 구현했습니다.

분석 단위는 데이터의 사업장 레코드입니다. 사업장별 가입자 수와 금액으로 파생 지표를 만들고, 업종코드를 기준으로 비교 집단을 구성합니다.

## 주요 기능

| 기능 | 구현 내용 |
| --- | --- |
| 기업 검색 | 정제한 사업장명으로 검색하고 가입자 수가 많은 순으로 정렬 |
| 사업장 정보 조회 | 주소, 업종, 가입자 수, 신규·상실 인원 표시 |
| 급여 지표 산출 | 사업장별 인당금액을 바탕으로 월·연 급여 추정치 계산 |
| 동일 업종 비교 | 동일 업종코드의 평균·개수·최소·최대와 검색 사업장의 추정치 비교 |
| 차이 해석 | 업종 평균 대비 금액 차이와 비율을 문장으로 표시 |
| 시각화 | 업종 평균과 검색 사업장의 월·연 급여 추정치를 막대그래프로 비교 |
| 업종 내 사업장 탐색 | 동일 업종에서 연간급여 추정치가 높은 사업장 상위 10개 표시 |

검색 결과가 여러 개이면 가입자 수가 가장 많은 첫 번째 사업장을 상세 분석 대상으로 사용합니다.

## 데이터 분석 과정

```text
국민연금 사업장 CSV
        ↓
데이터 로드 및 유효 레코드 선별
        ↓
컬럼 정리 · 사업장명 정제 · 파생 변수 생성
        ↓
기업 검색 및 동일 업종 통계 산출
        ↓
평균 대비 차이 계산 · 표와 차트 시각화
        ↓
Streamlit 대시보드에서 조회
```

### 1. 데이터 로드 및 전처리

- `Pandas`로 CP949 인코딩의 CSV를 읽습니다.
- 사업장업종코드의 결측값과 공백으로만 구성된 값을 제외하고, 업종코드를 정수형으로 변환합니다.
- 분석에 사용할 컬럼명을 정리하고 불필요한 컬럼을 제거합니다.
- 정규표현식으로 사업장명의 괄호 안 문자열과 특수문자를 제거하고 연속 공백을 정리합니다.
- 날짜에서 연도·월을, 주소에서 시도를 추출합니다.
- `가입상태 == 1`인 사업장만 분석 대상으로 유지합니다.

### 2. 급여 추정 지표 생성

현재 코드에 구현된 계산식은 다음과 같습니다.

```text
인당금액 = 금액 / 가입자수
월급여추정 = 인당금액 / 0.09
연간급여추정 = 월급여추정 × 12
```

`0.09`는 현재 구현에서 사용하는 고정 환산 계수입니다. 이 계산 결과는 실제 지급 급여를 검증한 값이 아니라, 입력 데이터와 해당 계수에 기초한 추정 지표입니다. 다른 기준 시점의 데이터에 적용하려면 원천 데이터의 금액 정의와 환산 계수의 적합성을 먼저 확인해야 합니다.

### 3. 비교 집단 구성 및 통계 분석

검색 사업장과 **업종코드가 같은 사업장**을 비교 집단으로 구성합니다. 월·연 급여 추정치에 대해 `mean`, `count`, `min`, `max`를 계산하고, 검색 사업장과 업종 평균의 차이를 산출합니다.

```text
업종 평균 대비 차이율(%) = (검색 사업장 월급여추정 / 업종 평균 월급여추정 - 1) × 100
```

업종 평균은 사업장별 급여 추정치의 **단순평균**이며, 가입자 수로 가중한 평균은 아닙니다. 비교 집단에는 검색 사업장도 포함됩니다.

### 4. 결과 전달

- 비교 통계와 동일 업종 상위 사업장을 표로 제공합니다.
- `Matplotlib` 막대그래프로 월·연 급여 추정치를 비교합니다.
- 평균 대비 금액 차이와 비율을 문장으로 표시해 결과 해석을 돕습니다.
- `st.cache_resource`로 데이터 로드 및 전처리 결과를 재사용합니다.

## 분석 결과를 해석할 때의 한계

- **급여 추정의 정확도:** 금액의 정의와 고정 환산 계수에 의존하므로 실제 평균 급여나 채용 제시 연봉으로 단정할 수 없습니다. 추정 오차를 검증한 결과는 포함되어 있지 않습니다.
- **사업장과 기업의 차이:** 같은 기업이 여러 사업장으로 나뉠 수 있습니다. 검색 결과의 첫 번째 사업장이 기업 전체를 대표한다고 볼 수는 없습니다.
- **비교 조건:** 같은 업종코드만 사용하며 지역, 규모, 직무, 경력 등의 차이는 통제하지 않습니다.
- **집계 방식:** 사업장별 단순평균이므로 업종 전체 가입자 기준 평균과는 다를 수 있습니다.
- **데이터 시점:** 단일 CSV에 대한 분석으로, 시계열 변화나 인과관계는 분석하지 않습니다.
- **데이터 품질 처리:** 가입자 수가 0인 경우의 나눗셈과 급여 지표의 이상치 처리 등은 보완이 필요합니다.
- **인원 지표:** 신규·상실 값은 원천 데이터의 항목으로, 실제 입사·퇴사 인원과의 일치 여부를 별도로 검증하지 않았습니다.

## 향후 개선 방향

아래 항목은 현재 구현과 구분한 개선 계획입니다.

- 데이터 기준 시점과 금액 정의를 검증하고 환산 계수를 설정값으로 관리
- 가입자 수 0, 결측값, 이상치에 대한 검증 및 예외 처리
- 검색 결과에서 사용자가 분석할 사업장을 직접 선택하는 기능
- 중앙값·분위수·가입자 수 가중평균을 추가해 비교 기준 확장
- 지역·가입자 규모를 함께 고려한 비교 집단 구성
- 여러 시점의 데이터를 수집해 가입자 수와 급여 추정치의 변화 분석
- 전체 실행 의존성을 명시하고 분석 로직과 화면 코드를 분리해 재현성 개선
